Reduce image file sizes, convert to next-gen formats, and bulk-optimize your media library through a cloud optimization service.

== Description ==

PicSqueeze automatically compresses images as you upload them and can bulk-optimize everything already in your media library.

Features:

* Automatic optimization on upload
* Three compression levels: Normal, Aggressive, Ultra
* WebP and AVIF conversion
* Bulk optimization with a progress bar
* Original image backup and one-click restore
* Optimization stats per image in the Media library

== Installation ==

1. Upload the `picsqueeze` folder to `/wp-content/plugins/`.
2. Activate the plugin through the Plugins screen.
3. Open Settings → PicSqueeze and enter your API key.
